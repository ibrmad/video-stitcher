# Module 6: Export (compact plan)

> Run inline (owner, 2026-10-05: speed up; compact plans, no review pause;
> TDD, checks and a self-review stay). Taken before Module 5: export is what
> makes the app usable end to end, and lens fine-tuning is for experts.

**Goal:** Export writes the stitched match:
- the export sheet: the output file with Save to…, resolution with its
  size, codec (from the probed list) and quality;
- the processing range: start and end (sliders and text), the duration, and
  a warning when the range is empty;
- record replay, and save AI debug events;
- Cancel and Export, with Export's enable rules.

While exporting, the export card shows progress and Cancel, and the
preview pauses. Afterwards the preview comes back where it was.

**Not in this part:** AI tracking (model, mode, detection interval, preset,
framing, pitch lock, lookahead, advanced panner). It lives in
`reco-autocam`, which another session is editing in this checkout; it
follows as Module 6b once that work lands (PARITY keeps the item open).

**Spec:** DESIGN.md row 6; PARITY.md Module 6; slint-inventory §2.11 and §7
(Export); reco-gui `export.rs` (`run_export`) and the export handlers in
`main.rs`.

## Decisions

- **The job.** `reco_app::export` holds `ExportOptions` (output, size,
  codec, quality, range in seconds, replay, events path) and
  `ExportJob::start(left, right, calibration, options, waker)`. It runs
  `reco_io::StitchJob` on a thread with a cancel flag and reports:
  - `Progress { frames, total, fps }`;
  - `Finalizing`;
  - `Done { path, frames, seconds }`;
  - `Failed(String)`;
  - `Cancelled`.

  The output gets `.mp4` when it has no extension.
- **Calibration.** The export uses the live tuned calibration, not only the
  saved file. The worker answers `PreviewCommand::Snapshot` with
  `PreviewEvent::Snapshot(MatchCalibration)`, and the export starts from
  that.
- **The preview during an export.** It closes (the worker keeps its
  thread), so the GPU and decoders are free. Afterwards it reopens and seeks
  back to the frame it showed (New).
- **Codecs.** h264, hevc and av1 are probed once
  (`reco_io::ffmpeg::encoder::available_encoders`) on a thread at startup.
  The dropdown lists what is available; h264 is the fallback.
- **Resolutions.** 1080p (1920×1080), 720p (1280×720), 2K (2560×1440) and
  4K (3840×2160), as the Slint app. Defaults come from settings
  (`export_*`) and are saved after each export.
- **The sheet** is a centred panel over the viewer (Rerun-style: band
  header, 24 pt rows). Esc or Cancel closes it.
- **Default output.** `{first left stem}_stitched.mp4` beside the first
  left file.
- **Checks.** The Save dialog is answered through the dialog seam
  (`"export"`). Exports are short ranges of the fast pair, written into a
  temporary folder.
